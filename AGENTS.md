# DAY / NEXT

Пользователь предпочитает русский язык и просит впредь давать ссылки на скачивание сборок **из GitHub-репозитория Eugene715x/DAY-NEXT**. Готовые HTML/ZIP собираются в `downloads/`; перед выдачей ссылки проверьте, что соответствующие файлы действительно опубликованы. Не подменяйте GitHub-ссылку локальным путём `/workspace` и не утверждайте публикацию до успешного push.

Проект без сторонних зависимостей: `npm start`, `npm test`, `npm run build`. Для обычной разработки используйте существующий checkout; облачная задача уже изолирована, дополнительный worktree не нужен.

Основная игровая платформа — ПК. Пользователь не планирует играть на мобильных устройствах; новые функции и ручные проверки ориентируйте на настольный браузер, не тратьте время на отдельный мобильный прогон без конкретной необходимости.

Карты: процедурная в `world.js`, реальная OSM-геометрия в `maps/usa.js`, конвертер в `scripts/lib/osm-converter.mjs`, её навигационная сетка в `real-world.js`. Сохраняйте атрибуцию ODbL, происхождение и историческую дату снимка. Не выдавайте декоративную текстуру за реальные высоты или вымышленные реки/леса за OSM-данные. Сезонное русло не является постоянной водной преградой.

Подложка `terrain-renderer.js` / Canvas `terrain-map` отделена от объектов на Canvas `map`. Не запекайте в подложку дороги, дома, водотоки или другие выбираемые объекты. Отрисовка, выбор, подсветка и выключение слоёв используют общий реестр в `detail-renderer.js`. Полноту импорта проверяйте относительно конкретного исходника и его `coverage`, а не заявляйте совпадение исторического снимка с современным сайтом OSM.

Слои определяются в `map-layers.js`: `landscape` объединяет природу и зоны землепользования как биомы; `water` содержит водоёмы и русла; `roads` содержит всю геометрию дорог, включая совмещённые теги highway/railway. Здания и остальные объекты отдельны. Используйте эту же классификацию для меток, отрисовки и выбора; не оставляйте скрытый объект в другом слое. Процедурная природа рисуется через `createLandscapeBackdrop` и также выключается слоем ландшафта. Видимость не меняет навигацию.

Парковки и территории учреждений также относятся к ландшафту. `mapZoneBiome` определяет тип участка; `zonesAt` в renderer возвращает все пересекающиеся зоны с учётом отверстий, независимо от видимости. Не заменяйте несколько зон одной выбранной. Сохраняйте здания отдельно; зональная проекция здания использует только его реальный контур, у точечных учреждений нет выдуманной площади. `npm run build` / `npm run map:report` обновляет полный список оставшихся объектов в `maps/source/remaining-objects.{json,md}`.

`power` — самостоятельный слой электросети. Полные границы собираются из подлинных участков в converter; отсутствующие части нельзя замыкать выдуманной линией. Административная территория не означает жилую застройку. `gameplay-types.js` задаёт стабильные типы и общие профили ресурсов; неизвестное назначение здания не угадывается по окружению, состояния руин и назначения независимы. Это ещё не система выдачи лута.

Производительность: game.js держит ограниченный кэш видимого участка с запасом для прокрутки, а renderer рисует подсветку отдельно через `drawHighlight`. Изменение масштаба, слоя, карты, размера окна или выход за запас должно инвалидировать кэш. Не возвращайте полную статическую отрисовку в каждый анимационный кадр. Проверяйте совпадение геометрии выбора и изображения после кэширования.
