# Реальные высоты Beatty / Rhyolite

`beatty-elevation.tif` — неизменённые байты Float32 GeoTIFF, экспортированного из официального **USGS 3D Elevation Program (3DEP) Bare Earth DEM Dynamic ImageServer**. Это высота земной поверхности, а не рисунок теней и не процедурный рельеф. URL запроса, параметры, ответ экспорта, сведения сервиса, исходные байты и SHA-256 сохранены отдельно.

- Географические границы: `[-116.86, 36.86, -116.73, 36.94]`, WGS84.
- Сетка: **769 × 593 = 456 017** измеренных/ресэмплированных значений, без пропусков.
- Шаг итоговой сетки: примерно **15,069 × 15,043 м**. Это шаг экспорта; исходный динамический сервис объединяет DEM разного разрешения. Значение глобального `pixelSize` сервиса не выдаётся за разрешение местного исходного продукта.
- Диапазон исходных высот: **926,690–1824,635 м**. Игровая сетка хранит значения с округлением до 0,1 м; это не заявление о точности высотных измерений.
- Применён билинейный ресэмплинг сервиса; искусственные холмы и заполнение пропусков не добавлены.
- Строки идут с севера на юг, столбцы — с запада на восток. Первая и последняя координаты сетки соответствуют границам карты. Параметры экспорта расширяют границы на половину ячейки, чтобы именно **центры** крайних пикселей совпали с углами игрового bbox.
- Вертикальный датум в полученных метаданных не указан; он сохранён как `null`. Преобразования вертикального датума не выполнялись. Время скачивания не подменяет дату высотной съёмки.

В описании сохранённого сервиса указано, что мозаика отражает опубликованные данные 3DEP по состоянию на 28 сентября 2026 года. Это дата состояния сервиса, не дата каждого местного измерения. Точное время скачивания находится в `beatty-elevation.provenance.json`.

Геоданные высот: **U.S. Geological Survey, 3D Elevation Program (3DEP)**. Данные USGS для США — public domain; сведения об источнике сохранены. Условия: https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits

## Воспроизведение

Игра использует готовый `maps/beatty-elevation.js` и работает без сети и без Python. Для авторской повторной конвертации GeoTIFF нужны Python 3.12 и библиотеки чтения растра:

```sh
python -m pip install rasterio==1.4.3 numpy==2.2.6
python scripts/import-elevation.py --rebuild
```

`--rebuild` использует сохранённый TIFF, проверяет SHA-256 и координаты центров, сохраняет время и байты исходника и не обращается к сети. Без этого аргумента импортёр запрашивает актуальный экспорт USGS и записывает новую provenance. Ошибка сервера, неполное покрытие или сдвиг координат не заменяют рабочую карту.

[Fetch Beatty elevation](https://github.com/Eugene715x/DAY-NEXT/actions/workflows/fetch-elevation.yml) выполняет то же получение на публичном GitHub runner. Это позволяет загрузить официальный источник даже когда облачный рабочий контейнер ограничивает прямой доступ к домену USGS. Workflow публикует только источник и игровую сетку высот; сборка игры выполняется отдельно.

`tests/import-elevation.test.mjs` независимо читает теги и все исходные Float32-ячейки TIFF встроенными средствами Node.js, проверяя геопривязку и согласованность каждого игрового значения с исходным в пределах округления.
