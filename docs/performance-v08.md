# Проверка производительности 0.8

Измерено 20 октября 2026 года в Chromium headless в общей облачной среде. Это сравнение двух версий в одинаковых условиях; результат не гарантирует такой же FPS на конкретном ПК.

Сцена: центр Битти, масштаб 6×, окно 1440 × 960, device scale factor 1. В каждой фазе измерены 120 кадров. Для перемещения использована одинаковая траектория из 120 шагов по 3 CSS-пикселя, всего 360 пикселей.

| Сценарий | 0.7, FPS | 0.8, FPS | 0.7, p95 кадра | 0.8, p95 кадра |
| --- | ---: | ---: | ---: | ---: |
| Неподвижная карта | 27.0 | 60.0 | 50.0 мс | 16.8 мс |
| Наведение на дом | 25.4 | 60.0 | 50.1 мс | 16.7 мс |
| Перетаскивание карты | 24.1 | 59.0 | 50.1 мс | 16.8 мс |

Первичная инициализация: 646 → 550 мс. Максимальный кадр при перемещении в новой версии — 50.0 мс; редкая перестройка кэша всё ещё может давать более длинный кадр.

Основное изменение — неподвижная геометрия больше не перерисовывается заново каждый кадр. Кэш содержит видимую область и запас по краям для перемещения. Подсветка выбранного объекта рисуется отдельно; пространственный индекс уменьшает число проверяемых объектов.

В неподвижной сцене число вызовов Canvas `stroke` на кадр уменьшилось примерно с 1625 до 5; создание линейных градиентов — с 392 до 1.

За 457 кадров выполнено 4 перестройки статической карты. Кэш занимал 2,873,344 пикселя, 10.96 МиБ. Это размер растрового кэша, а не всей памяти браузера.

## Проверка поведения

- После перемещения камеры и возврата выбранная область карты совпала по пикселям: средняя и максимальная разница 0.
- Выключение электросети убирает её изображение и выбор; включение восстанавливает те же пиксели. Изменение масштаба и переключение слоёв обновляют кэш.
- Сохранены 893 здания. 824 здания с недостаточными данными остаются неуточнёнными; расположение в жилой зоне не превращает их автоматически в дома.
- Медицинское здание в руинах сохраняет медицинский тип и отдельное состояние разрушения. Профили пересекающихся биомов объединяются без дубликатов.
- Замкнутая административная территория Битти сохраняет отдельный административный тип без придуманного списка ресурсов.
- Автономная сборка: 0 сетевых запросов и 0 ошибок JavaScript.

Подробные значения и параметры: [performance-v08.json](performance-v08.json). Диагностика текущей сборки доступна в `window.__DAY_NEXT__.getRenderStats()`; значения относятся к текущему запуску.
