# Скачать DAY / NEXT

[Скачать ZIP](https://github.com/Eugene715x/DAY-NEXT/raw/refs/heads/main/downloads/day-next.zip), распаковать и открыть `day-next.html` в браузере. Установка и интернет для игры не нужны.

В папке также лежит самостоятельный [HTML-файл](day-next.html). GitHub может показывать его как исходный код: используйте кнопку скачивания файла.

Сборки создаются командой `npm run build`. Включены реальная территория Битти / Райолит в Неваде, вымышленная карта и импорт/экспорт геоданных через атлас.

Версия 0.4: независимые подложка и слои объектов; исправлены выбор и подсветка дорог, восстановлены пропущенные категории OSM. Нажмите **«Слои»**, чтобы проверить дороги, здания, природные объекты и остальные объекты по отдельности. Отключённый слой не рисуется и не выбирается.

Кнопка дома справа или **B** показывает застройку. Колесо / жест двумя пальцами приближает до 24×; наведение / касание показывает сведения об объекте, включая дороги на обзорном масштабе.
