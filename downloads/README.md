# Скачать DAY / NEXT

[Скачать ZIP](https://github.com/Eugene715x/DAY-NEXT/raw/refs/heads/main/downloads/day-next.zip), распаковать и открыть `day-next.html` в браузере. Установка и интернет для игры не нужны.

В папке также лежит самостоятельный [HTML-файл](day-next.html). GitHub может показывать его как исходный код: используйте кнопку скачивания файла.

Сборки создаются командой `npm run build`. Включены реальная территория Битти / Райолит в Неваде, вымышленная карта и импорт/экспорт геоданных через атлас.

Версия 0.8: электросеть выделена в отдельный слой; полная граница Битти собрана в большую зону. Добавлены игровые типы зданий, биомов и общие профили ресурсов. Отрисовка карты кэшируется, а подсветка и путник обновляются отдельно. Разработка и проверки ориентированы на ПК.

В ZIP добавлен `remaining-objects.md` — полный список того, что осталось в слое остальных объектов. Он также доступен [в репозитории](../maps/source/remaining-objects.md).

`gameplay-types.json` содержит каталог типов и потенциальных ресурсов для будущей системы поиска. Механика добычи и выдача предметов ещё не добавлены.

Кнопка дома справа или **B** показывает застройку. Колесо / жест двумя пальцами приближает до 24×; наведение / касание показывает сведения об объекте, включая дороги на обзорном масштабе.

Нажмите **«Слои»**, чтобы независимо включать подложку, ландшафт, воду, дороги, здания и остальные объекты. Обновление исходника OSM через репозиторий и скачивание файла через атлас доступны как раньше.
